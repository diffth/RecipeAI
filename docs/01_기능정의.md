# 기능 정의 (MVP)

MVP 기능은 두 가지다: **F1 요리 이름 인식**, **F2 영양가 평가**. 사진 입력(F0)과 결과 화면(F3)이 둘을 감싼다.

## F0. 사진 입력

| 항목 | 정의 |
| --- | --- |
| 입력 방법 | 파일 선택, 드래그 앤 드롭, 모바일 카메라 촬영(`capture="environment"`) |
| 형식 | JPG, PNG, WEBP, HEIC/HEIF |
| 크기 | 최대 8MB |
| 미리보기 | 선택 즉시 표시 |
| 오류 | 형식 오류(415), 크기 초과(413), 업로드 실패(400)를 한국어 메시지로 표시 |

## F1. 요리 이름 인식

| 항목 | 정의 |
| --- | --- |
| 음식 여부 | `isFood`. 음식이 아니면 "음식 사진이 아닌 것 같습니다" 안내 후 종료 |
| 대표 이름 | 한국어 통용 이름(`nameKo`) + 영어 이름(`nameEn`) |
| 신뢰도 | 0~1 (화면엔 %). **60% 미만이면 "확실하지 않음"** 표시, 막대 색 변경 |
| 다른 후보 | 최대 3개, 신뢰도 내림차순. **대표 신뢰도 80% 이상이면 생략** (서버에서 강제) |

완료 기준: 흔한 한식·양식 사진에서 대표 이름이 맞고, 애매한 사진에서는 신뢰도가 낮게 나온다.

## F2. 영양가 평가

| 항목 | 단위 | 비고 |
| --- | --- | --- |
| 분량 가정 | 문장 | 사진 속 양 기준 1인분 (예: "1인분 약 400g, 밥 1공기 포함") |
| 칼로리 | kcal | |
| 탄수화물·단백질·지방 | g | |
| 탄단지 비율 | % | **서버에서 계산** (탄4·단4·지9 kcal), 합계 100% |
| 당류·식이섬유 | g | |
| 나트륨 | mg | |
| 평가 문장 | 문장 | 요약 1~2문장, 장점 1~3개, 주의점 0~3개 |

- 출처: Gemini 추정치. 화면 하단에 "영양 수치는 AI 추정치이며 실제와 다를 수 있습니다 (출처: Gemini 추정)" 고정 표기.

완료 기준: 인식한 요리에 대해 위 항목이 모두 채워지고, 수치가 현실적인 범위다.

## F3. 결과 화면

카드 3장으로 구성한다.

1. **요리 카드**: 이름, 영어 이름, 신뢰도 막대, 다른 후보
2. **영양 카드**: 분량 가정, 칼로리(큰 숫자), 탄단지 비율 막대와 g·%, 당류·식이섬유·나트륨
3. **평가 카드**: 요약, 👍 장점, ⚠️ 주의점, 사용 모델명

## F4. 레시피

분석 결과(음식일 때) 아래 "🍳 ○○ 레시피 보기" 버튼을 누르면 따로 요청한다.

| 항목 | 정의 |
| --- | --- |
| 출처 | Gemini 생성. 화면에 "AI가 생성한 레시피" 표기 |
| 기본 정보 | 이름, 한 줄 소개, 예상 시간(분), 난이도(쉬움·보통·어려움) |
| 재료 | 이름·수량·단위. 2인분 기준으로 받고, 1~10인분 조절 시 화면에서 비례 계산. "약간"처럼 수치 없는 재료는 그대로 |
| 조리 순서 | 번호 매긴 단계. 인분과 어긋나지 않도록 단계 문장에는 분량 숫자를 쓰지 않음 |
| 팁 | 사진 속 요리처럼 만드는 팁 1~3개 |
| 초기화 | 새 사진을 분석하면 이전 레시피는 사라짐 |

## API

`POST /api/analyze` — `multipart/form-data`, 필드 `image`

성공 응답(200):

```json
{
  "isFood": true,
  "dish": { "nameKo": "김치찌개", "nameEn": "Kimchi stew", "confidence": 0.82 },
  "alternatives": [{ "nameKo": "부대찌개", "confidence": 0.1 }],
  "servingAssumption": "1인분 약 400g (밥 제외)",
  "nutrition": { "calories": 320, "carbs": 14, "protein": 22, "fat": 19, "sugar": 5, "sodium": 1850, "fiber": 3.4 },
  "macroRatio": { "carbs": 18, "protein": 28, "fat": 54 },
  "assessment": { "summary": "…", "highlights": ["…"], "cautions": ["…"] },
  "model": "gemini-3.8-flash"
}
```

실패 응답: `{ "error": "한국어 메시지" }` — 400/413/415(입력), 500(API 키 없음), 502(Gemini 호출 실패·응답 형식 오류).

`POST /api/recipe` — `application/json`

요청: `{ "nameKo": "김치찌개", "nameEn": "Kimchi stew", "servingAssumption": "1인분 약 400g" }` (`nameKo`만 필수, 각 200자까지)

성공 응답(200):

```json
{
  "title": "돼지고기 김치찌개",
  "summary": "…",
  "timeMinutes": 30,
  "difficulty": "쉬움",
  "ingredients": [{ "name": "신김치", "quantity": 300, "unit": "g" }, { "name": "소금", "quantity": null, "unit": "약간" }],
  "steps": ["…"],
  "tips": ["…"],
  "servings": 2,
  "model": "gemini-3.5-flash"
}
```

실패 응답은 `/api/analyze`와 같다 (400·500·502).
