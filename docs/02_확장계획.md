# 확장 계획

MVP(요리 이름 인식 + 영양가 평가) 이후 순서. 우선순위는 아직 확정 전이다.

## 2차 목표: 레시피 안내

서비스의 최종 목적. 인식한 요리의 레시피를 보여 준다.

- 재료와 분량(인분 조절)
- 조리 순서, 예상 시간, 난이도
- 사진 속 요리와 비슷하게 만드는 팁
- 결정 필요: 레시피를 LLM이 생성할지, 공개 레시피 데이터에서 찾을지, 출처 표기 방식

## 정확도 개선

- 식약처 식품영양성분 DB(공공데이터포털) 연동으로 한식 영양 수치 보정. 매칭 실패 시 Gemini 추정으로 대체
- 여러 요리가 한 사진에 있을 때 요리별로 나눠 분석
- 사용자가 요리 이름·분량을 고치면 영양을 다시 계산

## 사용자 기능

- 분석 기록 저장, 하루 섭취량 합계
- 로그인
- 즐겨찾는 레시피

## 운영

- 배포(Vercel 등), API 키 서버 보관
- 호출 횟수 제한·요금 관리
