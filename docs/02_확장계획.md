# 확장 계획

MVP(요리 이름 인식 + 영양가 평가) 이후 순서. 우선순위는 아직 확정 전이다.

## 2차 목표: 레시피 안내 — 구현 완료

Gemini 생성 방식으로 구현했다 ([01_기능정의.md](01_기능정의.md) F4). 남은 개선:

- 사진을 함께 보내 사진 속 모양에 더 맞춘 팁 제공 (지금은 요리 이름과 분량 설명만 보냄)
- 공개 레시피 데이터와 비교·출처 링크
- 인분 조절 시 "0.3개" 같은 애매한 수치를 1/4·1/3 등 주방 단위로 표시

## 정확도 개선

- 식약처 식품영양성분 DB(공공데이터포털) 연동으로 한식 영양 수치 보정. 매칭 실패 시 Gemini 추정으로 대체
- 여러 요리가 한 사진에 있을 때 요리별로 나눠 분석
- 사용자가 요리 이름·분량을 고치면 영양을 다시 계산

## 사용자 기능

- 분석 기록 저장, 하루 섭취량 합계
- 로그인
- 즐겨찾는 레시피

## 운영

- 배포(Vercel 등), API 키 서버 보관
- 호출 횟수 제한·요금 관리
